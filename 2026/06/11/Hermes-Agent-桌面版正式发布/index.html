前言

经过数月的开发与优化，Hermes Agent 桌面版 v0.3.2 今日正式发布！最新更新日期：2026-06-10

这款由 NousResearch 打造的多模态 AI 助手终于拥有了独立的桌面应用，支持 Windows、macOS 两大平台，让用户能够更便捷地体验 AI 带来的效率提升。

Hermes Agent 是什么？

Hermes Agent 是一款基于 NousResearch 的多模态 AI 助手，它能够：

  • 智能对话：理解自然语言，进行流畅的问答交流
  • 代码生成：根据需求自动生成高质量代码
  • 图片生成：通过文字描述创作图片
  • 语音合成：将文本转换为自然语音
  • 视频生成：根据描述生成短视频

桌面版新特性

1. 全平台覆盖

本次发布的桌面版支持：

平台 版本要求 安装包大小
Windows Windows 10/11 ~120MB
macOS Apple Silicon + Intel ~95MB

2. 本地化运行

桌面版支持本地模型模式，用户可以选择：

  • 云端模式：使用 NousResearch 云端算力，响应更快
  • 本地模式：下载模型到本地，保护隐私，离线可用

3. 增强的交互体验

4. 系统集成

桌面版深度集成操作系统特性：

  • Windows：支持系统托盘常驻、快捷键全局呼出
  • macOS：支持 Touch Bar 原生控制、Dock 菜单

安装教程

Windows 用户

  1. 访问 中文社区下载页
  2. 下载 Windows 版本
  3. 解压文件，双击运行
  4. 启动程序并登录账号

macOS 用户

  1. 访问 中文社区下载页
  2. 下载 macOS 版本（支持 Apple Silicon + Intel）
  3. 解压并拖入应用程序文件夹
  4. 启动程序并登录账号
