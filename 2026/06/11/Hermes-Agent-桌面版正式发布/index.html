Hermes Agent 桌面版正式发布！Windows / macOS / Linux 全平台支持

发表于2026-06-11|更新于2026-06-11|软件发布
|浏览量:

前言

经过数月的开发与优化，Hermes Agent 桌面版今日正式发布！这款由 MiniMax 打造的多模态 AI 助手终于拥有了独立的桌面应用，支持 Windows、macOS、Linux 三大平台，让用户能够更便捷地体验 AI 带来的效率提升。

Hermes Agent 是什么？

Hermes Agent 是一款基于 MiniMax 大语言模型的多模态 AI 助手，它能够：

  • 智能对话：理解自然语言，进行流畅的问答交流
  • 代码生成：根据需求自动生成高质量代码
  • 图片生成：通过文字描述创作图片
  • 语音合成：将文本转换为自然语音
  • 视频生成：根据描述生成短视频

桌面版新特性

1. 全平台覆盖

本次发布的桌面版支持三大主流操作系统：

平台 版本要求 安装包大小
Windows Windows 10 及以上 ~120MB
macOS macOS 11 Big Sur 及以上 ~95MB
Linux Ubuntu 20.04 / Debian 11 及以上 ~85MB

2. 本地化运行

桌面版支持本地模型模式，用户可以选择：

  • 云端模式：使用 MiniMax 云端算力，响应更快
  • 本地模式：下载模型到本地，保护隐私，离线可用

3. 增强的交互体验

4. 系统集成

桌面版深度集成操作系统特性：

  • Windows：支持系统托盘常驻、快捷键全局呼出
  • macOS：支持 Touch Bar 原生控制、Dock 菜单
  • Linux：支持 Wayland/X11 自动适配
