🌉 Hermes Agent Bridge Server 教程：让本地 HTML 调通任意 LLM

发表于2026-06-14|更新于2026-06-14|编程教程AI辅助开发

🎯 这篇教程解决什么问题

你有没有这样的经历：

  • 写了个 HTML 小工具，想让 AI 帮用户解答问题
  • 一调 fetch("https://api.openai.com/...") 就报 CORS 错
  • 浏览器 file:// 协议下连 localhost 都不让请求
  • API key 又不敢直接写进 HTML，怕别人右键看源码就拿走

Bridge Server 就是为这些问题而生的。

一个本地 Python 小服务，专门帮你的 HTML 把 LLM 调用”翻译”成合法的后端请求。

全部代码 250 行，只依赖 Python 3 标准库，零安装。

📦 它能做什么

能力 说明
🚪 HTTP 网关 暴露 POST /chat 端点，浏览器可直接调用
🔑 API key 托管 key 存服务器环境变量，HTML 端只发请求
🛡️ CORS 自动处理 预检、跨域头都帮你写好
🧪 MOCK 模式 没配 key 也能跑，先验证 HTML 联通
🔌 OpenAI 兼容 任意兼容 OpenAI 协议的模型都能接（mimo / deepseek / 豆包 / 通义千问 …）
📊 健康检查 GET /health 一眼看当前模型和模式

❓ 常见问题

Q1: 浏览器报 CORS 错？

✅ Bridge 已经处理了所有 CORS 头(代码里的 CORS_HEADERS)。
如果你仍然报错,检查:

  • Bridge 服务是否真的启动(看 cmd 窗口)
  • 端口是否被占用(改 BRIDGE_PORT=8766 然后 HTML 里也改)

Q2: 报 upstream HTTP 401?

API key 不对,或者该平台要求用单独的 header(比如 Azure)。
检查:

  • key 是不是复制完整(常多/少空格)
  • key 是不是过期了
  • 平台文档里有没有特殊 header 要求

Q3: HTML 双击打开调不通?

file:// 协议下,浏览器默认禁止调 http://localhost,但 Chrome/Edge 通常会放行。
如果不行,试:

  • 在 chrome://flags/ 启用 Allow file URLs to access localhost
  • 或者 python -m http.server 8000 起个静态服务再访问

📝 总结

你刚学到的东西：

  • 用 Python 标准库写一个 HTTP 网关
  • 让 file:// 协议的 HTML 也能调 LLM
  • 用环境变量管理 API key
  • 一键切换多个 OpenAI 兼容模型
  • MOCK 模式让你无 key 也能先联通

Bridge 的真正威力不在 Bridge 本身,而在它把”前端 HTML”和”后端 LLM”解耦了——以后你写任何小工具,只要在 HTML 里写 5 行 fetch,AI 能力就是开箱即用的。
