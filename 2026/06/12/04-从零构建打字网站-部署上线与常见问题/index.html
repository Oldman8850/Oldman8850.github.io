🚀 部署到 Vercel（最简单的方法）

第一步：上传代码到 GitHub

1. 创建 GitHub 仓库

  1. 打开 https://github.com
  2. 登录后，点击右上角 + → New repository
  3. 仓库名输入：typing-practice
  4. 选择 Private
  5. 点击 Create repository

2. 推送代码

打开终端，进入项目文件夹：

第二步：部署到 Vercel

1. 注册 Vercel

  1. 打开 https://vercel.com
  2. 点击 Sign Up
  3. 用 GitHub 账号登录（最方便）

2. 部署项目

  1. 点击 Add New Project
  2. 点击 Import Git Repository
  3. 选择你刚创建的仓库
  4. 点击 Deploy

3. 等待完成

  • 等待 1-2 分钟
  • 看到绿色 ✅ 就成功了！
  • 你会获得一个免费域名：xxx.vercel.app

🎉 恭喜！你的网站已经上线了！

❓ 常见问题解答

Q1: 我不会编程，能完成吗？

可以！ 只要你：

  • ✅ 会打字
  • ✅ 会复制粘贴
  • ✅ 会用浏览器
  • ✅ 愿意花时间学习

AI Agent（Claude）会帮你写代码，你只需要理解逻辑、测试功能、提出需求。

Q2: 需要多少钱？

项目 费用
开发工具 免费
GitHub 账号 免费
Vercel 托管 免费（每月 100GB）
域名 约 30元/年（可选）

总计：0元起 💰

Q3: 需要多久？

阶段 时间
环境安装 1-2 小时
基础打字功能 1-2 天
键盘可视化 1-2 天
后端和数据库 2-3 天
测试和修复 1-2 天
部署上线 1 小时

总计：约 1 周

Q4: 遇到错误怎么办？

步骤 1：看错误信息

复制错误信息，发给 Claude。

步骤 2：描述清楚问题

❌ 错误：”报错了”

✅ 正确：”运行 npm run dev 后出现这个错误：

我已经安装了 react 18.2.0，请问怎么解决？”
