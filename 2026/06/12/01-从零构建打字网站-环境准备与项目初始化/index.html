🖥️ 你需要准备什么

硬件要求

项目 最低配置
内存 4GB+
硬盘 10GB 可用空间
网速 能访问 GitHub

软件要求

  1. ✅ 一台电脑（Windows/Mac/Linux 都可以）
  2. ✅ 一个 GitHub 账号（免费）
  3. ✅ 一个 Vercel 账号（免费部署）
  4. ✅ 一个 Claude 账号（AI 编程助手）

🔧 第一步：安装开发工具

1️⃣ VS Code（代码编辑器）

  1. 打开浏览器访问 https://code.visualstudio.com/
  2. 点击下载按钮
  3. 双击安装包，一路点”下一步”

2️⃣ Node.js（运行环境）

  1. 打开 https://nodejs.org/
  2. 下载 LTS 版本（长期支持版）
  3. 安装后，按 Win+R，输入 cmd，回车
  4. 输入 node --version，显示版本号即成功

3️⃣ Git（版本控制）

  1. 打开 https://git-scm.com/
  2. 下载 Windows 版本
  3. 安装时全部用默认选项
  4. CMD 输入 git --version 验证
